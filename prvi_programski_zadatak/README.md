# Prvi programski zadatak - cjeloviti izvještaj

Rješenje svih zadataka (1-4) za grupu 10 na jednom mjestu.

- [Izvještaj (PDF)](./Internet_stvari_prvi_programski_zadatak_grupa10.pdf): postupak, rezultati, slike, ispis rezultata i Python kod
- [rjesenje_grupa10.md](./rjesenje_grupa10.md): izvorni tekst izvještaja
- [analiza.py](./analiza.py): svi odzivi i frekvencijske karakteristike, sprema slike i `rezultati.txt`
- [s_plane.py](./s_plane.py): polovi i nule u s-ravnini
- [izvjestaj.py](./izvjestaj.py): izrada PDF-a iz teksta, slika i koda

## Pokretanje

Potreban je [uv](https://docs.astral.sh/uv/). Naredbe se pokreću iz ove mape:

```
uv run python analiza.py
uv run python s_plane.py
uv run python izvjestaj.py
```
